# PROSPECT 0.37.0 — Real-Time Football Engine

## Совместимость

Патч накопительный: в него включены исправления CI/build hotfix v4. Его можно ставить поверх базовой 0.36.0 или поверх уже исправленной 0.36.0.

## Цель

Заменить декоративное воспроизведение заранее рассчитанного исхода настоящим игровым снэпом. Игрок непосредственно управляет своим футболистом, а остальные 21 участник принимают ограниченные позиционные решения внутри симуляции.

## Главное

- симуляция обновляется покадрово через `requestAnimationFrame`;
- все игроки имеют позицию, скорость, направление, цель, маршрут и состояние контакта;
- результат не существует до завершения живого розыгрыша;
- QB может двигаться за линией скримиджа, выбирать любого ресивера, бежать или выбрасывать мяч;
- защита двигается, закрывает маршруты, преследует мяч, делает sack, tackle, breakup и interception;
- мяч существует отдельно от игроков и летит к вычисленной точке упреждения;
- статистика формируется из событий конкретного снэпа.

## Простое управление

Интерфейс не показывает внутренние AI-решения. У каждой позиции максимум три действия:

| Позиция | Действия |
|---|---|
| QB | пас по кнопке ресивера, бежать, выбросить |
| RB | рывок, финт, закрыть мяч |
| WR/TE | ускориться, срезать, ловить |
| OT/OG/C | силовой блок, якорь |
| EDGE/DT | speed rush, power rush |
| LB/CB/S | к мячу, тэкл, перехват |
| K/P | удар |

Движение выполняется WASD, стрелками или экранной крестовиной.

## Режимы матча

- `auto` использует быстрый симулятор полного матча;
- `key-moments` запускает real-time engine только в важных снэпах;
- `every-snap` запускает real-time engine на каждом снэпе героя.
