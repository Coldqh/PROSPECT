# PROSPECT 0.42.1 — Hotfix report

## Исправлено

1. **Interception return pursuit**
   - нападение больше не преследует returner строго в текущую точку;
   - учитываются направление движения и дистанция до мяча;
   - скорость pursuit немного повышена только после turnover;
   - физический перехват может закончиться tackle, turnover return или defensive touchdown в зависимости от расположения игроков.

2. **Offensive line grading**
   - pressure или sack allowed всегда помечают `Protection` как обязательную зону исправления;
   - итоговый score и четыре основных критерия позиции не изменены.

## Проверено

- forced physical interception → interception → tackle → turnover;
- OL sack allowed → grade D и correction `Protection`;
- 10 real-time engine regression cases;
- 18 position grading regression cases;
- TypeScript `--noEmit`;
- source, UI, match, control, pro, lifecycle и grading architecture checks.
