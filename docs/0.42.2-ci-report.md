# PROSPECT 0.42.2 — Professional test suite CI report

## Симптом

GitHub Actions завершал `npm run test` с кодом 1 после успешного выполнения всех 13 тестов `src/sports/football/pro/draft.test.ts`.

Фактический результат:

- `13 passed`;
- игровая логика не падала;
- единый worker работал около 133 секунд;
- после завершения Vitest фиксировал внутреннюю ошибку RPC `Timeout calling "onTaskUpdate"`.

## Корень проблемы

Один test-файл повторно строил полный карьерный мир, драфт, тренировочный лагерь и профессиональную лигу почти для каждого сценария. Повышение `testTimeout` разрешало отдельным тестам работать дольше, но не сокращало жизнь worker и не устраняло RPC timeout.

## Решение

- `draft.test.ts` оставлен для шести тестов процесса драфта;
- `camp.test.ts` содержит четыре сценария лагеря, состава и недельной подготовки;
- `league.test.ts` содержит три тяжёлых интеграционных сценария матча, полного сезона и practice squad;
- общая подготовка вынесена в `professionalTestFixtures.ts`;
- camp/league fixtures создаются один раз через `beforeAll`;
- каждый тест получает независимую копию `CareerSave` через `structuredClone`;
- три файла запускаются отдельными командами Vitest;
- используется чистое окружение `node` и pool `forks`.

## Что не менялось

- игровые формулы;
- логика драфта;
- составы и salary cap;
- симуляция матчей и сезона;
- save schema;
- пользовательские сохранения.

## Локальные проверки

- `npm run typecheck`;
- `npm run check:professional-league`;
- `npm run check:boundaries`;
- `npm run check:ui`.

Полный GitHub Actions прогон должен подтвердить устранение платформенной RPC-ошибки после установки патча.
