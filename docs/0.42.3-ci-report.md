# PROSPECT 0.42.3 — CI and hero marker report

## Причина hotfix

В 0.42.2 монолитный professional suite был разделён на три файла, но `camp.test.ts` всё ещё выполнял:

1. тяжёлое создание активной профессиональной карьеры;
2. два отдельных завершения training camp;
3. проверки roster, free agency и weekly preparation в одном worker.

Суммарное время файла достигало 65 секунд. Все четыре теста завершались успешно, но Vitest worker терял RPC-связь с главным процессом и возвращал `Timeout calling "onTaskUpdate"`.

## Исправление

Professional integration suite теперь разделён на семь независимых процессов:

- draft;
- camp roster decision;
- camp free agency;
- league structure and weekly preparation;
- interactive match;
- practice squad week;
- complete season and offseason.

Каждый процесс создаёт только необходимый fixture и содержит не более одного тяжёлого сценария. Суммарное количество тестов осталось прежним: 13.

## Визуальная правка

Hero marker и hero assignment route в `RealTimeMatchField` теперь зелёные:

- marker: `#35c96f`;
- route: `rgba(61,220,116,.95)`.

Цвет соперников, партнёров, special teams и мяча не изменён.

## Выполненные локальные проверки

- TypeScript project build: PASS;
- source boundaries: PASS;
- UI architecture: PASS;
- match experience architecture: PASS;
- professional league architecture: PASS;
- seamless match control: PASS;
- professional career architecture: PASS.
