# PROSPECT 0.42.1 — Build Hotfix

Исправляет два падения CI после 0.42.0.

## Interception return

После перехвата игроки нападения теперь строят упреждающий pursuit angle по направлению движения returner. Раньше они бежали в его текущую точку с меньшей скоростью и почти гарантированно отпускали защитника в pick-six.

## Performance grading

Если OT, OG или C допускает pressure либо sack на пасовом розыгрыше, `Protection` принудительно попадает в список corrections. Остальные критерии и итоговая оценка сохраняются.

## Save compatibility

Save schema не менялась. Сохранения 0.42.0 совместимы напрямую.
