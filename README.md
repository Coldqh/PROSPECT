# PROSPECT

Браузерная игра о жизни и карьере игрока в американский футбол.

## Текущий этап — 0.30.0

- нижняя навигация: **Профиль / Дом / Команда**;
- сезон, матчи, таблица, рекрутинг, социальная жизнь, лента и рейтинг находятся в боковой панели;
- отдельные экраны игрока, команды, матча, драфта и социальных связей;
- единая мобильная геометрия под iPhone 14 Pro: симметричные отступы 20 px, safe-area и отсутствие горизонтального переполнения;
- один шрифт Inter и фиксированная типографическая шкала;
- один набор токенов цвета, размеров, радиусов, контролов и анимаций;
- CSS разделён по ответственности; старые версионные слои отключены;
- автоматическая проверка дубликатов селекторов, перегруженных файлов, микротекста, вторых шрифтов и ошибок навигации;
- игровая логика и схема сохранений не изменены.

## Команды

```bash
npm install
npm run dev
npm run test
npm run build
```
