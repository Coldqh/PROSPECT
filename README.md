# PROSPECT

Браузерная игра о жизни и карьере игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.38.0

- игровое поле использует настоящие ярды и показывает только 36-ярдовый участок вокруг мяча;
- камера следует за розыгрышем, поэтому короткое движение больше не выглядит скачком на двадцать ярдов;
- на поле отображаются номера ярдов, хэши, линия скримиджа и линия первого дауна;
- HUD показывает четверть, живое игровое время, down & distance и фактическую позицию мяча;
- после каждого снэпа поле фиксирует итог, ярды, новую отметку, first down, turnover или touchdown;
- пас летит по физической траектории: неточный бросок падает в свободную зону, а перехват требует реального контакта защитника с мячом;
- после перехвата начинается настоящий возврат, который атакующая команда может остановить;
- QB не может двигаться до получения снэпа и свободно продолжает играть за линией скримиджа после него;
- ПК использует стрелки, телефон — перетягиваемый аналоговый джойстик;
- длинные розыгрыши и тачдауны проходят по всей стометровой модели поля без искусственного ограничения старого экрана;
- сохранения 0.37.0 совместимы, новая миграция не требуется.
