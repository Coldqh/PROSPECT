# PROSPECT

Браузерный симулятор карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.49.0

- повторяющиеся социальные конфликты ограничены cooldown и больше не спамят каждую неделю;
- агентность учитывает реальную ценность игрока и положение внутри position room;
- пересмотр роли сохраняет непрерывный depth chart без одинаковых рангов;
- один участник не создаёт несколько одинаковых конфликтов за сезон;
- story и transaction одного решения сохраняются как один факт истории;
- добавлены инварианты качества симуляции без новой доменной надстройки;
- save schema 35, ecosystem module 14, IndexedDB schema 2.
