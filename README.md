# PROSPECT

Браузерный симулятор жизни и карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.41.0

- бесшовное управление: герой выполняет назначение автоматически, касание джойстика мгновенно перехватывает движение, отпускание возвращает автопилот;
- ИИ продолжает маршрут, блок, coverage, rush или движение с мячом из текущей позиции без резкого возврата;
- отдельное окно итога каждого снэпа и сниженная вероятность перехватов сохранены;
- единый карьерный ID игрока от школы через колледж и драфт до профессиональной лиги;
- настоящий draft class формируется из живых выпускников автономного мира;
- выбранные игроки попадают в pro-ростеры с прежним именем, позицией, рейтингом, колледжем и историей;
- выпускники без выбора выходят на рынок свободных агентов;
- фоновая школьная и университетская экосистема продолжает развиваться во время pro-карьеры героя;
- в World добавлен карьерный архив с командами, стадией, драфтом и хронологией событий;
- автоматическая миграция schema 29 → 30.
