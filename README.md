# PROSPECT

Браузерная игра о жизни и карьере игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.39.0

- после драфта и training camp карьера больше не заканчивается статусной карточкой;
- шестнадцать профессиональных клубов получают реальные активные ростеры по 53 игрока;
- practice squad хранится отдельно и не занимает место в активном лимите;
- зарплаты, dead cap, payroll и свободное место считаются внутри общего salary cap;
- клубы автономно закрывают потребности через рынок свободных агентов;
- регулярный сезон состоит из 15 недель и 120 матчей, затем проходит плей-офф из семи игр;
- герой играет профессиональные матчи через тот же real-time football kernel;
- depth chart, coach trust, статистика, результаты, таблицы и транзакции сохраняются между неделями;
- offseason старит контракты, выпускает ветеранов, создаёт rookie pool, проводит free agency и открывает следующий профессиональный сезон;
- отчисленный игрок получает реальные предложения и может подписать однолетний контракт;
- сохранения schema 27 автоматически мигрируют в schema 28.
