# PROSPECT

Браузерный симулятор карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.51.0

- десктопная карьера получила левую рабочую навигацию и более широкое пространство менеджера;
- рекрутинг стал настоящей доской программ с цветами команд, плотными строками и выделенной выбранной школой;
- рынок использует новостную сводку, табличные движения и цветовые идентификаторы команд;
- College и PRO получили визуальный центр сезона с табло, главным матчем и брендированными таблицами;
- светлые редакционные поверхности выделяют главное, а не превращают весь экран в одинаковые карточки;
- игровая логика и схема сохранений не изменены;
- save schema 35, ecosystem module 14, IndexedDB schema 2.

## Команды

```bash
npm install
npm run dev
npm run test
npm run build
```

## Установка патча на Windows

```powershell
cd C:\PROSPECT
powershell -ExecutionPolicy Bypass -File .\APPLY_PATCH_0.51.0.ps1
```
