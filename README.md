# PROSPECT

Браузерный симулятор карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.54.0

- все основные менеджерские экраны используют один тёмный command header и единый рабочий каркас;
- рекрутинг, рынок, College, PRO, лента мира, драфт и матч больше не выглядят отдельными поколениями интерфейса;
- расписания, рейтинги, переходы и решения получили явные заголовки колонок и постоянный контекст сезона;
- профессиональный переход и драфт используют общую карточку игрока и единые поверхности;
- игровая логика и схема сохранений не изменены;
- save schema 35, ecosystem module 14, IndexedDB schema 2.

## Команды

```bash
npm install
npm run dev
npm run test
npm run build
```

## Установка патча на Windows

```powershell
cd C:\PROSPECT
powershell -ExecutionPolicy Bypass -File .\APPLY_PATCH_0.54.0.ps1
```
