# PROSPECT

Браузерная игра о жизни и карьере игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.37.0

- реальный снэп работает покадрово, а не проигрывает заранее рассчитанную анимацию;
- 22 игрока двигаются, реагируют на мяч, блоки, маршруты и соперников;
- QB свободно двигается за линией скримиджа, выбирает любого доступного ресивера, бежит сам или выбрасывает мяч;
- мяч реально летит к точке упреждения, защита может сделать breakup или interception;
- pass rush сжимает карман, защитники преследуют носителя и делают тэкл в конкретной точке поля;
- у каждой позиции осталось только 1–3 понятных действия, вся остальная логика скрыта внутри AI;
- управление работает с клавиатуры, мышью и экранной крестовиной;
- автоматический матч использует быстрый симулятор, ключевые моменты и каждый снэп — real-time engine;
- результат живого розыгрыша напрямую формирует ярды, события и статистику;
- сохранения 0.36.0 совместимы, новая миграция не требуется.
