# PROSPECT

Браузерный симулятор карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.48.0

- игроки, тренеры и программы самостоятельно оценивают роль, доверие, схему, результаты и деньги;
- конфликты проходят стадии concern, meeting, ultimatum и resolved;
- NPC могут добиваться новой роли или выходить в трансферный портал;
- программы меняют roster plan и тактическое направление под последствиями результатов;
- штабы получают ультиматумы и перестраивают координаторов;
- герой не отправляется в портал без решения игрока;
- save schema 35, ecosystem module 14, IndexedDB schema 2.

## Команды

```bash
npm install
npm run dev
npm run test
npm run build
```
