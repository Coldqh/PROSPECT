# PROSPECT

Браузерный симулятор карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.47.0

- реальные события и транзакции становятся неизменяемыми фактами истории мира;
- связанные факты формируют долгие линии игроков, тренеров, программ и rivalry;
- команды, главные тренеры и заметные игроки получают автономные сезонные цели;
- сюжетные новости создаются только после подтверждённых глав симуляции;
- активные линии видны в мировой ленте;
- история ограничена по размеру и проверяется в многосезонной симуляции;
- save schema 34, ecosystem module 13, IndexedDB schema 2.

## Команды

```bash
npm install
npm run dev
npm run test
npm run build
```
