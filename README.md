# PROSPECT

Браузерный симулятор жизни и карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.43.0

- итоговая оценка матча рассчитывается по роли, производству и цене ошибок;
- 8 TKL, 7 TFL, 7 SACK и 10 PRESS дают 93/A вместо 67/C;
- QB читает прогрессию, реагирует на давление и покидает разрушающийся карман;
- устранены повторные попытки pass rush внутри одной блокировочной дуэли;
- автоматические маршруты и движение стабилизированы без дрожания у точек;
- после неуправляемого драйва показывается функциональное окно смены сторон;
- экран матча очищен от инструкций, повторов счёта и нефункциональных описаний;
- колледжи и PRO-команды доступны через отдельный раздел «Лиги»;
- recruiting и рынок собраны в понятные списки и фильтры;
- autosave хранит один активный snapshot и пять периодических резервных копий;
- save schema остаётся 31.
