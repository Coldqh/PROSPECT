# PROSPECT

Браузерный симулятор карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.52.0

- старый тёмный карточный интерфейс полностью удалён вместе с 22 устаревшими CSS-файлами;
- приложение использует одну светлую браузерную систему спортивного менеджера;
- верхняя панель, постоянная навигация, плотные таблицы и квадратные рабочие панели образуют единый shell;
- рекрутинг, рынок, College, PRO, команда, карьера и матч оформлены внутри одного визуального языка;
- декоративные version layers, мягкие вложенные карточки и старый operations override больше не участвуют в каскаде;
- мобильная версия сохраняет рабочую иерархию без отдельного старого дизайна;
- игровая логика и схема сохранений не изменены;
- save schema 35, ecosystem module 14, IndexedDB schema 2.

## Команды

```bash
npm install
npm run dev
npm run test
npm run build
```
