# PROSPECT

Браузерный симулятор карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.50.0

- рекрутинг показывает список школ, выбранную программу, причину интереса и следующий контакт на одном экране;
- рынок начинается со сводки недели, реальных движений и открытых потребностей команд;
- раздел Лига стал центром сезона College и PRO;
- главный матч, изменения рейтинга, гонки конференций, плей-офф и кадровые решения видны без поиска по лентам;
- интерфейс использует футбольные формулировки вместо кодов FIT / NEED / DEPTH / PORT / OFFR;
- доменная логика и схема сохранений не изменены;
- save schema 35, ecosystem module 14, IndexedDB schema 2.

## Команды

```bash
npm install
npm run dev
npm run test
npm run build
```

## Установка патча на Windows

```powershell
cd C:\PROSPECT
powershell -ExecutionPolicy Bypass -File .\APPLY_PATCH_0.50.0.ps1
```
