# PROSPECT

Браузерная игра о жизни и карьере игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.36.0

- три режима матча: автоматический, ключевые моменты и каждый снэп;
- отдельный Analysis Mode с честным прогнозом выполнения, влияния, big play и риска ошибки;
- плавное воспроизведение pre-snap, snap, развития комбинации, действия с мячом, контакта и результата;
- продвижение мяча, line of scrimmage, first-down marker и итог каждого розыгрыша прямо на поле;
- полная статистика ручных и автоматических снэпов героя;
- точные pressure, punt return yards и kick distance;
- матчи отмечаются в недельном календаре как GAME или FINAL;
- карьера доступна за все 14 позиций, а составы содержат реальных игроков depth chart;
- сохранения автоматически мигрируют до схемы 27.
