# PROSPECT

Браузерный симулятор жизни и карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.40.0

- три режима управления героем: ассистированный, ручной и полный автомат;
- автотраектории и выполнение назначения до момента владения мячом;
- отдельное окно итога каждого снэпа поверх игрового поля;
- сниженная и ограниченная вероятность перехватов;
- профессиональная недельная подготовка: плейбук, техника, восстановление и борьба за depth chart;
- динамический состав, травмы, questionable/out/IR, замены и возвращения;
- автономный trade deadline и кадровые транзакции;
- 16 клубов, ростеры по 53 игрока, salary cap, регулярка и плей-офф;
- новая футбольная заставка загрузки;
- автоматическая миграция schema 28 → 29.

## Команды

