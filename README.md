# PROSPECT

Браузерный симулятор карьеры игрока в американский футбол внутри автономной спортивной экосистемы.

## Текущий этап — 0.53.1

- главная сезона, профиль команды и профиль игрока полностью пересобраны без старой React-композиции;
- интерфейс использует тёмные слоистые поверхности, крупные OVR-щиты, карточки игроков и статусные бейджи;
- команда получила цельный masthead, нормальную таблицу состава и отдельные позиционные комнаты;
- профиль игрока получил сильную иерархию имени, рейтинга, роли, статистики и физических качеств;
- главный экран показывает неделю, готовность, следующий блок и расписание как единый игровой центр;
- игровая логика и схема сохранений не изменены;
- save schema 35, ecosystem module 14, IndexedDB schema 2.

## Команды

```bash
npm install

```
